# `database-demo/` — Demo Seeds, Fixtures & Test Data

> **Status:** Planned — structure initialized

## Overview
Non-production database workspace for **W.I.N.K** seed scripts, sample campus/city fixtures (FSM & Monastir), and **NeonDB** preview-branch or local mock datasets.

## Purpose
- Populate realistic demo profiles, hobbies, venues, meetups, and chat threads for [`frontend-demo/`](../frontend-demo) and [`backend-demo/`](../backend-demo).
- Test schema migrations and query edge cases on isolated **NeonDB branches** without touching production user data.
