# `frontend-demo/` — Frontend Prototype & Demo Sandbox

> **Status:** Planned — structure initialized

## Overview
Isolated frontend sandbox for prototyping **W.I.N.K** UI concepts, interactive presentations, animations, and mock-data user flows without affecting production code in [`frontend/`](../frontend).

## Purpose
- Rapidly test visual ideas and UX variations proposed in [`/plan/iyed.md`](../plan/iyed.md).
- Provide a self-contained demo UI (paired with [`backend-demo/`](../backend-demo) or mock fixtures) for live showcases and offline previews.
- Validate components before promoting them into [`frontend/`](../frontend).
