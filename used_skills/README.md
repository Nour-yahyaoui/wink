# `used_skills/` — AI Learned Skills & Project Engineering Notes

This folder is dedicated to capturing:
1. **Skills & reusable patterns** learned by AI coding agents and contributors while working on **W.I.N.K**.
2. **Project notes**, architectural trade-offs, debugging takeaways, and domain insights maintained by **Nour (`@Nour-yahyaoui`)**.

## Files in This Directory

| File | Purpose |
|---|---|
| [`SKILLS_LOG.md`](./SKILLS_LOG.md) | Structured catalog of technical & workflow skills learned during W.I.N.K development so future sessions and contributors build faster and avoid repeating mistakes. |
| [`PROJECT_NOTES.md`](./PROJECT_NOTES.md) | Ongoing engineering scratchpad, architectural observations, benchmarks, and reminders across phases. |

## How to Add a New Skill or Note

- When an AI session or engineering sprint uncovers a valuable pattern (e.g., NeonDB connection pooling on Vercel serverless functions, Vercel Blob client-upload token signing, Google OAuth session edge cases, Next.js-to-Render CORS/cookie setup), add a numbered skill entry in [`SKILLS_LOG.md`](./SKILLS_LOG.md).
- Keep general observations, links, and rough technical notes inside [`PROJECT_NOTES.md`](./PROJECT_NOTES.md).
